## 🎯 COLOR CODING

### Signal Colors:
- 🟢 **GREEN** = BUY Signal / Bullish Pattern
- 🔴 **RED** = SELL Signal / Bearish Pattern  
- 🟡 **YELLOW** = NEUTRAL / Wait for better signal

### Background Colors:
- **Light Green Box** = Strong BUY signal
- **Light Red Box** = Strong SELL signal
- **Light Yellow Box** = Candlestick patterns
- **Light Blue Box** = Technical indicators
- **White Box** = General information

- Charts medium size

- Sidebar becomes top menu
- Charts stack vertically
- Metrics in 2x2 grid

### Mobile (375x667):
- Hamburger menu
- Single column layout
- Swipe between sections
